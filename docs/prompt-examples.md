# Prompt Examples

These examples are for **translation only**. MTPE, proofreading, editing, revision, and linguistic review are outside the scope of the translation skills in this repository.

Replace `[TARGET LANGUAGE]` and, where relevant, `[SOURCE LANGUAGE]` with the languages required for the task.

## Minimal translation

```text
Translate into [TARGET LANGUAGE]:

[TEXT]
```

## Explicit language pair

```text
Translate the following text from [SOURCE LANGUAGE] into [TARGET LANGUAGE]:

[TEXT]
```

## Domain context

```text
Translate the following legal text into [TARGET LANGUAGE]. Preserve the source structure and use established target-language legal terminology:

[TEXT]
```

## Audience and purpose

```text
Translate the following text into [TARGET LANGUAGE] for a professional B2B audience. Preserve the source meaning, register, and level of formality:

[TEXT]
```

## Use configured terminology and preferences

```text
Translate the following text into [TARGET LANGUAGE]. Apply the terminology and editorial preferences configured in the skill:

[TEXT]
```

## Preserve protected content

```text
Translate the following text into [TARGET LANGUAGE]. Preserve all placeholders, variables, URLs, HTML tags, identifiers, and numbering exactly where they are protected content:

[TEXT]
```

## Project-specific instruction

```text
Translate the following text into [TARGET LANGUAGE]. For this project, translate [SOURCE TERM] as [APPROVED TARGET TERM]. This project-specific instruction takes priority over general preferences:

[TEXT]
```

## Formatting-sensitive translation

```text
Translate the following text into [TARGET LANGUAGE]. Preserve headings, paragraph breaks, list structure, labels, and meaningful capitalization:

[TEXT]
```
